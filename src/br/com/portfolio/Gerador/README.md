# Gerador de Senhas - Java 
Aplicação desktop desenvolvida em Java.

## Direferença desse projeto esse projeto incrementa o front do senha-seguras##

## Tecnologia: 
Utiliza java.security.SecureRandom. 

## Funcionalidades:
Conjunto de Caracteres: Inclui letras, números e símbolos
Geração de Senha: Cria senha com comprimento definido
pelo usuário - através do Scanner.

## Segurança: 
Usa java.security.SecureRandom
(criptograficamente forte)

## Foi opcional eu criar: Implementação da classe java.util.Scanner
Exemplo de Uso:
Comprimento da Senha: 12 caracteres
Resultado: Exibe a senha gerada no console:
Senha gerada: PrTFx(Gan=Rj
